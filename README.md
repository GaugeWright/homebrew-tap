# Homebrew Tap For WhippleScript

This tap will publish the Homebrew formula for the `whip` CLI after the first
tagged WhippleScript release publishes stable GitHub Release assets.

Expected install command after the formula is published:

```sh
brew tap jamesjscully/tap
brew install whipplescript
```

The formula should use the tagged release archive and SHA256 from
`https://github.com/jamesjscully/whipplescript/releases`.
